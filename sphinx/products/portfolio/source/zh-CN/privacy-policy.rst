Portfolio 隐私政策
==================

  *最后更新：2026 年 9 月 9 日*

  *产品：Portfolio 0.8 演示版，包括 Synode、Android 和 Windows 客户端（含广告）*

本隐私政策旨在更好地服务于关心自己的“个人身份信息”（PII）在网上如何被使用的用户。按照美国隐私法和信息安全领域的定义，PII 是指可单独或与其他信息结合使用，以识别、联系或定位某个人，或在特定情境下识别某个人的信息。

请仔细阅读本隐私政策，以清楚了解我们的应用如何收集、使用、保护或以其他方式处理用户的个人身份信息。

我们会从 Portfolio 用户处收集哪些个人信息？

在 Android 设备上安装 Portfolio 进行文件同步时，系统可能会视情况请求你授予 Portfolio 访问录音、外部存储或其他内容的权限，以便把你的文件同步（上传）到文件服务器。

Portfolio 计划使用第三方广告服务（例如 Google 广告），但不打算使用第三方服务（例如 Google Analytics）分析用户数据。

我们在此告知 Portfolio v0.8 的用户：除用于在服务器上管理文件外，用户的个人信息不会被用于任何其他用途。

AdMob 和 AdSense 的广告要求可概括为 AdMob 和 AdSense 的广告原则，其目的是为用户提供良好的体验。

https://support.google.com/admob/answer/6128543?hl=en

日志数据
--------

我们在此告知：当你使用我们的服务时，如果应用发生错误，我们会（通过第三方产品）在用户手机上收集称为“日志数据”的数据和信息。日志数据可能包括用户设备的互联网协议（“IP”）地址、设备名称、操作系统版本、使用服务时应用的配置、用户使用服务的日期和时间，以及其他统计信息。

Portfolio 是否使用 Cookie？
---------------------------

Portfolio 的 Android 和 Windows 客户端在任何情况下都不使用 Cookie。

通过 Portfolio 共享的文件可以用网页浏览器浏览，浏览器会使用 Cookie 识别已登录的用户。这些数据仅在客户端处理，不会在网络上传输，也不会作其他用途。

EXIF 与地理位置
---------------

EXIF 是媒体文件的元数据。

每个媒体文件上传到家庭文件服务器时，服务器会尝试解析其 EXIF 数据，并将解析出的地理位置数据保存到数据库中。当用户共享照片时，其他用户也可以看到这些地理位置。

如果文件的 EXIF 中没有地理位置数据，则不会保存任何地理位置，也不会获取用户的当前位置；因此，地理位置数据并不总能被正确解析。

此功能用于按地理位置对照片进行分组。

安全保障与第三方披露
--------------------

Portfolio 会定期从第三方服务（包括 Google Play 和 AdMob）获取报告。

除非事先通知用户，Portfolio 支持团队不会出售、交易或以其他方式向外部各方转让个人身份信息。

当为遵守法律、执行我们的应用政策，或保护我们或他人的权利、财产或安全而有必要时，我们可能会披露相关信息。

但是，非个人身份信息可能会被提供给其他方，用于营销、广告或其他用途。

文档共享政策
------------

在 Portfolio 0.8 中，上传到某个 Synode 的所有文件最终都会被复制到你的同步域中设置为同步存储节点的每一台设备上。这些设备可能归其他用户所有，并可完全访问该域的存储。用户有责任不在特定域中共享自己的敏感文档（文件）。

- **重要**：
  
  所有上传的文件都发送到由你（用户）拥有并设置的服务器。我们不会在自己的服务器或系统上存储、处理或访问你的文件。除法律要求外，我们不会出售、交易你的数据，也不会与第三方共享。

Android 应用权限
----------------

Portfolio（Android 演示版）会请求以下权限：

- **网络访问：**

  用于把文件上传到你指定的服务器。

- **访问网络状态：**

  用于检查网络连接，以获得最佳性能。

- **读取外部存储 / 媒体：**

  用于读取设备上的音频、图片、视频和其他文件，以便上传和管理。

- **相机权限：**

    Portfolio 演示版请求访问设备相机，用于识别二维码以添加服务器地址。我们致力于保护你的隐私，确保以负责任的方式处理你的个人信息。以下是我们使用和管理相机权限的方式：

    - **用途：**

    相机权限仅用于扫描二维码。

    - **数据收集：**

    授予相机权限后，应用可能会拍摄二维码图像，并且只使用符合 Portfolio 演示版格式的数据。只有服务器地址会被添加为新选项，其他数据不会被保存或用于任何用途。

    授予相机权限即表示你同意应用按上述方式使用此功能。如果你对数据的使用方式有任何疑虑或问题，请参阅完整的隐私政策或联系我们。

这些权限是应用正常运行所必需的。你可以在设备设置中管理这些权限。

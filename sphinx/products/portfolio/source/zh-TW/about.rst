關於
====

Portfolio 是一個用於管理和同步個人文件的系統，由多個部署的儲存節點和客戶端組成。

如果你認為把文件儲存、管理和整理在自己的電腦上很重要，那麼 Portfolio 正適合你！

Portfolio 目前是示範版本。使用者須自行照看上傳到伺服器（通常是一台個人電腦）上的檔案。

網路拓撲
--------

v0.8.# 示範版會在使用者的同步網域內，自動同步使用者上傳到任一伺服器的檔案。下文將檔案儲存節點稱為 *Synode*。

::

        -------------------
        |    domain-hub    |
        |    ^       ^     |
        |    |       |     |
        | node-1    node-1 |
        -------------------
            ^         ^
            |         |
        mobile-1   device-2 ...

..

 - domain-hub：可透過公網 IP 存取的伺服器

 - node 1 和 2：私有檔案儲存，通常是個人電腦。

該結構基於邊緣計算骨幹網路，開發者計劃將其擴展為不受網路拓撲限制的點對點節點。

.. _about-volume:

關於磁碟區（Volume）
--------------------

磁碟區是伺服器檔案系統中的一個資料夾，由使用者在設定服務節點時指定。上傳的檔案和資料都儲存在其中。

.. warning::

    請勿改動磁碟區資料夾中的資料。移動或修改其中的檔案會導致不可預知的結果。

另外，請勿把磁碟區切換到其他位置，儘管在 v0.7.0 中服務仍能執行。

Portfolio 0.8 的限制
--------------------

- 需要在公網 IP 主機上部署一個中樞 Synode，供其他 Synode 存取。

- Synode 數量固定，部署後無法更改。

- 檔案儲存容量有限——中樞節點的儲存成本可能較高。

近期規劃
________

- 提供雲服務，供使用者規劃自己的網域。

- 中樞節點可以排程儲存，只保留可公開存取的檔案。

- Synode 可以加入和離開網域。

另外，Portfolio 的邊緣計算骨幹網路還能做更多事情。詳見 `技術細節討論（英文） <https://github.com/odys-z/semantic-jserv/blob/master/docsync.jserv/README.md>`_。

What to download

A Portfolio domain is a group of storage nodes (Synodes) that keep copies of each other's files. Clients (Android, Windows Desktop) upload files to a Synode of the domain. Pick the packages for the role of each machine:

PackageWhat it isWho needs itRequirements
Synode
synode-<version>-x64_windows-<market>-<community>.zip
synode-<version>-x64_linux-<market>-<community>.tar.gz		 The file storage node (server). Saves uploaded files in its volume folder and synchronizes them with the other Synodes of the domain. Includes a setup GUI and installs itself as system services. Every domain needs one hub Synode on a host reachable by public IP, plus one Synode on each private computer that should keep a copy of the files. Choose the zip for Windows, the tar ball for Linux. Python 3.12 for setup; Windows 10+ or 64-bit Linux; Linux also needs exiftool. A JRE 17 is downloaded during setup.
Desktop
desktop-<version>-<market>-<community>.zip		 The Windows client for browsing, uploading and managing files on a PC. Not needed on a Windows computer that runs a Synode, since the Synode package already installs it. Download it only for a Windows PC that uses a domain without hosting a Synode. Windows 10+
Android
portfolio-<version>.apk		 The mobile client. Uploads photos, videos, audio and other files from the phone. Anyone uploading from an Android phone. It connects to a Synode that is already set up, by scanning the QR code shown in the Synode's setup. Android 8.0+
Manual
portfolio-<version>-<lang>.pdf		 The offline PDF of the online documents. Optional, for reading offline. A PDF reader

Market and community

Synode and Desktop packages are listed under a MARKET (the release channel, e.g. alpha) and a COMMUNITY (the organization whose registry the package is preconfigured for). Download the packages of the community you are joining, and use the same community for every Synode and Desktop in a domain.

Typical setups

  • Starting a new domain: a Synode on a public-IP host as the hub, then a Synode on each home or office computer, then the Android app on phones.
  • Joining an existing domain: a Synode on your computer (Windows users get the Desktop client with it), and/or the Android app.
  • Phone only: just the Android app, connected to a Synode someone in the domain has already set up.

下載哪些資源

Portfolio 的一個網域（domain）由若干儲存節點（Synode）組成，各節點互相保存檔案副本。用戶端（Android、Windows 桌面版）將檔案上傳到網域中的某個 Synode。請依每台裝置的用途選擇下載套件：

下載套件用途執行需求
Synode（Linux）
下載清單中顯示為：Synode … (x64_linux)		 檔案儲存節點，命令列安裝。上傳的檔案儲存在其磁碟區（volume）資料夾中，與網域中其他 Synode 同步，並以系統服務方式執行。 64 位元 Linux；需要 Python 3.12 和 exiftool。安裝過程會自動下載 JRE 17。
Synode（Windows）
下載清單中顯示為：Synode … (x64_windows)		 檔案儲存節點，圖形介面安裝。作用與 Linux 版相同，並會同時安裝 Windows 桌面版。 Windows 10+；需要 Python 3.12。安裝過程會自動下載 JRE 17。
桌面版
下載清單中顯示為：桌面端 …		 Windows 用戶端，用於在電腦上瀏覽、上傳和管理檔案。 Windows 10+
Android
下載清單中顯示為：Portfolio …（Android 版）		 手機用戶端，用於上傳手機中的照片、影片、音訊及其他檔案。 Android 8.0+
使用手冊
下載清單中顯示為：Portfolio … 使用手冊（PDF，…）		 線上文件的離線 PDF 版本。 PDF 閱讀器

發佈渠道與社群

Synode 與桌面版下載套件依發佈渠道（MARKET，如 alpha）和社群（COMMUNITY，即套件預先設定的註冊中心所屬組織）分組列出。請下載你要加入的社群的套件，同一個網域中所有的 Synode 和桌面版應使用同一社群。

常見部署方式

  • 建立新網域：先在公網 IP 主機上部署 Synode 作為中樞節點，再在家中或辦公室的電腦上各部署一個 Synode，最後在手機上安裝 Android 應用程式。
  • 加入既有網域：在自己的電腦上部署 Synode（Windows 使用者會同時取得桌面版），和/或安裝 Android 應用程式。
  • 只用手機：只需安裝 Android 應用程式，並連線到網域中他人已部署好的 Synode。

資料安全聲明

Portfolio 用於個人私有文件的同步。 Portfolio 0.8 依「現狀」（AS IS）發佈。使用者文件儲存在安裝時由使用者指定的磁碟區（volume）資料夾中。 目前版本僅供展示，尚未針對文件安全進行完整測試，使用者須自行留意並負責其文件的狀態。
安裝本軟體即表示使用者同意上述條款。

下载哪些资源

Portfolio 的一个域（domain）由若干存储节点（Synode）组成，各节点互相保存文件副本。客户端（Android、Windows 桌面端）把文件上传到域中的某个 Synode。请按每台设备的用途选择下载包：

下载包用途运行要求
Synode（Linux）
下载列表中显示为：Synode … (x64_linux)		 文件存储节点，命令行安装。上传的文件保存在其卷（volume）文件夹中，与域中其他 Synode 同步，并以系统服务方式运行。 64 位 Linux；需要 Python 3.12 和 exiftool。安装过程会自动下载 JRE 17。
Synode（Windows）
下载列表中显示为：Synode … (x64_windows)		 文件存储节点，图形界面安装。作用与 Linux 版相同，并会同时安装 Windows 桌面端。 Windows 10+；需要 Python 3.12。安装过程会自动下载 JRE 17。
桌面端
下载列表中显示为：桌面端 …		 Windows 客户端，用于在电脑上浏览、上传和管理文件。 Windows 10+
Android
下载列表中显示为：Portfolio …（Android 版）		 手机客户端，用于上传手机中的照片、视频、音频及其他文件。 Android 8.0+
用户手册
下载列表中显示为：Portfolio … 用户手册（PDF，…）		 在线文档的离线 PDF 版本。 PDF 阅读器

发布渠道与社区

Synode 与桌面端下载包按发布渠道（MARKET，如 alpha）和社区（COMMUNITY，即下载包预先配置的注册中心所属组织）分组列出。请下载你要加入的社区的下载包，同一个域中所有的 Synode 和桌面端应使用同一社区。

常见部署方式

  • 新建一个域：先在公网 IP 主机上部署 Synode 作为中心节点，再在家中或办公室的电脑上各部署一个 Synode，最后在手机上安装 Android 应用。
  • 加入已有的域：在自己的电脑上部署 Synode（Windows 用户会同时获得桌面端），和/或安装 Android 应用。
  • 只用手机：只需安装 Android 应用，并连接到域中他人已部署好的 Synode。

数据安全声明

Portfolio 用于个人私有文档的同步。 Portfolio 0.8 按“现状”（AS IS）发布。用户文档保存在安装时由用户指定的卷（volume）文件夹中。 当前版本仅供演示，尚未针对文档安全进行完整测试，用户须自行留意并负责其文档的状态。
安装本软件即表示用户同意上述条款。

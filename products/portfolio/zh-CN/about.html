关于

Portfolio 是一个用于管理和同步个人文档的系统，由多个部署的存储节点和客户端组成。

如果你认为把文档保存、管理和整理在自己的电脑上很重要，那么 Portfolio 正适合你！

Portfolio 目前是演示版本。用户须自行照看上传到服务器（通常是一台个人电脑）上的文件。

网络拓扑

v0.8.# 演示版会在用户的同步域内，自动同步用户上传到任一服务器的文件。下文将文件存储节点称为 Synode。

-------------------
|    domain-hub    |
|    ^       ^     |
|    |       |     |
| node-1    node-1 |
-------------------
    ^         ^
    |         |
mobile-1   device-2 ...

  • domain-hub：可通过公网 IP 访问的服务器

  • node 1 和 2：私有文件存储，通常是个人电脑。

该结构基于边缘计算骨干网络，开发者计划将其扩展为不受网络拓扑限制的点对点节点。

关于卷（Volume）

卷是服务器文件系统中的一个文件夹，由用户在设置服务节点时指定。上传的文件和数据都保存在其中。

警告

请勿改动卷文件夹中的数据。移动或修改其中的文件会导致不可预知的结果。

另外，请勿把卷切换到其他位置，尽管在 v0.7.0 中服务仍能运行。

Portfolio 0.8 的限制

  • 需要在公网 IP 主机上部署一个中心 Synode，供其他 Synode 访问。

  • Synode 数量固定，部署后无法更改。

  • 文件存储容量有限——中心节点的存储成本可能较高。

近期规划

  • 提供云服务，供用户规划自己的域。

  • 中心节点可以调度存储，只保留可公开访问的文件。

  • Synode 可以加入和离开域。

另外，Portfolio 的边缘计算骨干网络还能做更多事情。详见 技术细节讨论（英文）。
